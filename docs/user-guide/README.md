# Education OS user guides

Plain-language guides for the people who use Education OS: students, teachers, staff and administrators. They are not
for developers. Each guide says what each panel on a dashboard shows, what to do when a panel has nothing to show or
says its data is not available, and the common tasks the panels lead to.

They describe the panels as built on 5 November 2026. A panel that is not built yet is marked "Not built yet" in the
guide.
